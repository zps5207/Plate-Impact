1. Purpose and target material

Valerie's plate-impact model needs the matrix of the embedded-fiber plate to be elastic-plastic with ductile damage, inside the hex VUEL that hosts the fibers. Native material cards cannot drive a user element, so the constitutive law was written in the VUEL and verified against native Abaqus.

PropertyValue (SI)
ElasticityE = 700 MPa, ν = 0.45, ρ = 980 kg/m³
PlasticityJ2, yield 70 MPa, no hardening
Damage onsetequivalent plastic strain 0.1 at 0.01 /s, triaxiality 1/3
Damage evolutionenergy based, linear, Gf = 1460 J/m²

The fiber model (uniaxial, rate-dependent, tension-only) is a separate VUMAT and is paused; it is not covered here.

Open item. Valerie's deck Meshing/Vals.inp uses a matrix fracture strain of 0.01, the brief says 0.1. The brief was kept authoritative and all tests use 0.1. It is a single constant (EPS_F in the case generator) if this should change.

4. The model

Selected with props(14) = MAT_MODEL = 1; 0 keeps the previous behaviour bit-for-bit. 39 properties, 159 state variables.

  1. Kinematics and stress. The element stays Total Lagrangian (internal force = ∫ BLT S dV0, 2×2×2 Gauss). The law is multiplicative Hencky elasticity: from F and the stored Cp-1 form be = F Cp-1 FT, take principal log strains, Kirchhoff stress τ = λ tr(ε) I + 2με, and return S = F-1 τ F-T to the force assembly.
  2. Yield. J2 on Cauchy stress, q ≤ σy J. Flow is isochoric so the radial return in log space is exact: dγ = (qtrial − σy J)/(3μ). PEEQ is the logarithmic equivalent plastic strain, as native reports.
  3. Damage onset. When PEEQ ≥ εf(rate), σy0 and the rate are frozen.
  4. Evolution (Abaqus energy, linear). ū = L(PEEQ − PEEQonset), ūf = 2Gf/σy0, D = ū/ūf in [0,1], monotonic; S = (1−D) Sundamaged. L = (η V0)1/3 with full reference volume V0 and η = 1 − Vf (consistent with the embedded-fiber volume correction).
  5. Element death. Damage is per Gauss point; when all 8 reach D = 1 the element is latched dead (rhs = 0, dtimeStable = 1e30).
  6. Energy. Stress power is (1−D)(dψ + q dγ): plastic dissipation ALLPD carries a (1−D) weight and ALLDMD is the released elastic energy ψ dD (native's definition).
  7. Rate dependence. Table of yield vs rate, linear in log10(rate), clamped outside; default rate measure is the plastic strain rate (native-like), switchable to total.
  8. Stable increment. The lumped brick's volumetric mode is up to √3 faster than the 1D bar estimate, so the Stage 8 path uses an extra 1/√3.

An independent line-by-line Python port of the return map (verification/hencky_reference.py) confirms: uniaxial Cauchy stress plateaus at 70.0000 MPa with PEEQ = ln λ − σy/E, and simple shear gives Mises 70 MPa.

5. Method

  • Roles: the drafter agent wrote the first-pass Fortran, a Python reference, the deck generator and the sbatch (T-042); the hub (Claude Code) reviewed, ran everything on ROAR, and found and fixed the problems below.
  • Tests: a 1 mm cube in tension (0.5 nominal strain), compression (−0.4) and simple shear (1.0), at 0.01, 1 and 1000 /s, smooth-step loading. Every VUEL deck has a native twin (one C3D8R, same boundary conditions and step).
  • Output: nodal displacement and reaction history plus ALLIE, ALLPD, ALLKE, ALLDMD, ALLWK, dumped to CSV on ROAR and compared locally. Native ALLIE already contains ALLPD and ALLDMD, so the native balance is ALLWK = ALLIE + ALLKE; the VUEL one is ALLWK = ALLIE + ALLPD + ALLDMD + ALLKE.

7. Known deviations from native

  • The VUEL is full integration (8 Gauss points); native is C3D8R (1 point). Homogeneous single-element tests cannot expose hourglass or integration differences.
  • Native uses a Hughes–Winget / corotational rate form; the VUEL is hyperelastic-based. They agree to under 1% here (nominal strain up to ~0.3), but would differ for large rotations combined with plasticity, which the cantilever will show.
  • Rate dependence is log10-linear between table points; native tabular is linear in rate. They match only at table points.
  • VUEL ALLIE is elastic only; native ALLIE includes ALLPD and ALLDMD. Compare through the balance.
  • A user element cannot trigger native element deletion or SPH conversion; D = 1 zeroes the force and uses the dead-element path.
  • The Stage 8 stable increment is 1/√3 smaller than before, up to 1.7× more increments. The legacy MAT_MODEL = 0 path is unchanged and its estimate looks marginal for ν = 0.45 (not re-examined).

8. Not yet verified

  • The 0.01 /s set on the fixed Fortran (the earlier run used pre-fix code and was cancelled). The matrix is rate independent so it adds little.
  • The multi-point rate table path against Abaqus (a one-point table only so far).
  • Embedded fibers (η < 1), the combined matrix-and-fiber case, and the cantilever case.
  • Wave propagation and non-uniform softening, and the interaction of Gauss-point damage with the all-points death rule.
  • The Vals.inp fracture strain of 0.01 versus the brief's 0.1.
