Vals ball-failure tests (bt2): beam vs truss fibers, D4, max degradation 0.8

Six 12 µs native Vals decks (8 tasks, 32 GB, via run.sh), ROAR ctv/bt2. All six completed. Three variants at 1000 m/s and the same three at 500 m/s (still a 12 µs window, so the ball is earlier in its penetration). 1000 m/s references: vp5 and b4_d4fix (truss + D4 + max degradation 1). There is no 500 m/s reference deck, so the 500 m/s runs are only compared with each other. Ball-hex inversion = fraction of ball C3D8R elements with a non-positive corner Jacobian in the last output frame within 12 µs, computed from node positions (ball_inversion.py); it is a geometric count and does not know whether an element was deleted.

Correction (2026-10-28). The “ball hexes inverted” figures in this report were computed from node positions over all ball hexes, including elements the solver had already deleted. Matching per-element STATUS from the ODBs (b4_d4fix and c2_truss_d4_md80 at 1000 m/s) shows 609 of 610 and 618 of 619 inverted hexes were already deleted when they first inverted, and 0–1 live ball hexes are inverted at 12 µs. So the inversion column measures the leftover nodes of deleted elements, not live element failure. The 12 µs ball-deletion counts are unaffected. Also, ODB energies were mislabelled 1000 times too small in the first version of this report (the ODB is in J; the ball carries 3.55 kJ); this is fixed. Details: verification/roar/ball_tests/t051/inv_alive_analysis.py.

Analysis

  • Energy is fine everywhere. ETOTAL ends within 0.3% of its start in all runs.
  • Beam fibers + D4 (c1) are not clearly more stable at 1000 m/s. Ball inversion ends at 3.3%, against 3.6% for b4 (truss + D4) and 3.9% for vp5: a small difference from one run each. Ball deletion is lower (728 against 840), but beam fibers delete 63 fibers from 4.5 µs, against 11 for b4. Interface points past 50% damage are 934 against 912.
  • Max degradation 0.8 does not change the picture. c2 (truss) against b4: 784 against 840 ball deletions, 3.57% against 3.55% inverted, and 0 failed interface points against 13. c3 (beam) against c1: 753 against 728 ball deletions, identical 3.28% inversion. As flagged beforehand, it only acts on the matrix; the ball and fibers fail abruptly.
  • Beam fibers vs truss. Beam decks delete 63–68 fibers at 1000 m/s against 11–16 for truss, and 4–5 against 0 at 500 m/s. They also cost about 3.5 times the run time (5.3 h against 1.5 h at 1000 m/s). First fiber deletion is only slightly earlier with beams (4.2–4.5 µs against 4.5–5.4 µs).
  • At 500 m/s ball deletion is 1.8–2.0% and inversion 1.5–1.7% at 12 µs, with no spread worth reading between variants. Erosion starts at 3.3 µs, later than at 1000 m/s (1.8 µs).
  • Overall: none of the three changes stops ball erosion. The spread between variants is a few percent of the ball, each is one run with no repeat, and the deletion count is roughly 4–5% at 1000 m/s for every deck, so it looks set by the ball and impact rather than by these material choices. (The inversion column should not be read as live-element failure; see the correction above.)

Limits: one run per variant, 12 µs only, output frames sampled coarsely (vp5 about every 1.75 µs, bt2 about every 0.3 µs), so first-deletion times are not comparable between vp5 and the rest. vp5 is read at its last frame within 12 µs (10.5 µs).
