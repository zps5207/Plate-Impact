## Decision on your blocker (the user's design, final)
Interfaces must coincide exactly, because cohesive contact needs the surfaces initially touching. So the plies are TRUE translations: every top node of the one-ply Part is `bottom + step_full / N` where `step_full` is the median top-minus-bottom pair vector (your `step_full`), the same vector for every node. Do NOT shrink each top node by its own `(top - bottom)/N`. Consequence: the stacked top deviates from the source top by the translation residual (76 um on `Flatv2_curved.inp`, which is a source-mesh artifact; the intended input is a clean one-hex-thick mesh). Report that residual (max/mean/p95) and `expected_interface_gap_max` must now be 0. Keep the existing tolerance check and error.
