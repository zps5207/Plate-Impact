# T-028
role: refiner
round: 1
goal: Build the ply-partition core of the new plywise mesher: take a plate meshed with ONE hex element through the thickness, split it into N plies (N given, or from a target ply thickness), and emit a deck where one ply Part is duplicated as N Instances so top/bottom surfaces keep the same names and plies are told apart by instance. No fibers and no cohesive interaction in this task.

## Design decisions (the user's, do not re-litigate)
- Input deck = whole plate as one Part, in-plane mesh at the desired density, exactly ONE hex through the thickness. The per-hex thickness pairing is NOT guaranteed to be nodes 1-4 vs 5-8 (T-027, running in agents/drafter, is fixing exactly this in `embmesh/stacked.py`). Do not edit `stacked.py`; write your own small per-hex oriented-face helper in `embmesh/plywise.py` using `embmesh.geometry.hex_thickness_axis` plus the sign table in `hex_volume`/`inverse_hex`, and keep it isolated so the Hub can swap in T-027's helper later.
- Ply count: `--plies N` OR `--ply-thickness t` (N = max(1, round(T_mean / t)); report the resulting thickness). Report T_min/mean/max.
- One ply Part = the original in-plane mesh with each top node moved to `bottom + (top - bottom)/N` (one hex thick, node pairing preserved). Instances `Ply-1 .. Ply-N` differ by a pure translation `(k-1) * step`, step = (top - bottom)/N. This requires the original top face to be a translation of the bottom face (the "front and back faces are identical surfaces" assumption). Check it with the same relative-tolerance idea as `stacked.py` (0.11 x median in-plane edge; report max/mean/p95) and raise a clear `EmbmeshError` (see `embmesh/errors.py`) if violated. Do not loosen silently.
- Ply Part gets an element set `PLY` (all hexes). Surfaces are emitted at ASSEMBLY level in the exact CAE style of the user's reference deck `Meshing/stack.inp` (lines ~59211-59320): per instance and per face id an internal element set `*Elset, elset=_<surf>_S<n>, internal, instance=<inst>` (use `generate` ranges when contiguous, as CAE does) followed by `*Surface, type=ELEMENT, name=<surf>` listing `_<surf>_S<n>, S<n>`. Name them `Ply-<k>_bottom` / `Ply-<k>_top`. That deck's `back` surface mixes S2/S3/S4 on one plate, which confirms the face id must be chosen PER HEX. Do not rely on dotted part-level surface references (unverified in Abaqus). Face id per hex (S1 = nodes 1-2-3-4, S2 = 5-6-7-8, S3 = 1-2-6-5, S4 = 2-3-7-6, S5 = 3-4-8-7, S6 = 4-1-5-8) according to the oriented stack axis. Bottom = lower stack coordinate. Also provide a function returning interface pairs `[("Ply-k_top", "Ply-(k+1)_bottom")]` for the later cohesive task (T-030), nothing more.
- The original plate instance may carry a rotation (stack.inp: `Plate-1` is rotated 90 deg about an axis, `Plate-2` is not). `embmesh.model.Instance.transform` translates THEN rotates about an assembly-frame axis, so a translation added to a rotated instance gets rotated too. Bake the original instance transform into the ply Part node coordinates (world frame), so every `Ply-k` instance is a pure world-frame translation with no rotation block. Test with a rotated source instance.
- Section/material assignment of the original plate must carry over to the ply Part. Any assembly-level set/surface/BC in the original deck that names the old plate instance must be reported (list them in the RESULT as a concern); rewrite them to cover all plies only if that is simple and safe, otherwise leave and report.
