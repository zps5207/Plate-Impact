# T-022
role: refiner
round: 1
goal: P0 curved-plate check on the REAL (irregular, quarter-disc) mesh: build a one-element-thick version of the curved Flatv2 deck, lay prototype 0/90 mid-surface fibers on it, and report whether fibers stay inside their host hexes and inside their ply. Must be memory-light (the full-deck mesher run was killed by low memory).

## Why
We are adding a ply-wise mesher mode (read `docs/PLYWISE_COHESIVE_MESHER_PLAN.md`, copy in inbox/T-022/). Plies are a pure translation stack: the back face is the front face translated by one stack vector; every ply has the same in-plane hex mesh. Fibers: one unidirectional layer per ply, along the two global axes perpendicular to the stack axis, straight in projection along the stack axis, height at the ply mid-surface (centered). Pitch is measured in the projected plane. A regular-grid prototype (`p0_curved.py`, copy in inbox) passed every check, but that fixture is parallelograms in projection, which makes the test nearly trivial. The real Flatv2 plate is an irregular quarter-disc mesh (C-mesh), so this is the real test.

## Inputs
- `inbox/T-022/Flatv2_curved.inp`: Flatv2 with the Plate part warped by a spherical sag (R = 0.25 m, 5.05 mm at the edge, about 11.5 degrees max slope). Only node coordinates in `*Part, name=Plate` changed. Units are metres. The Plate has 24,000 C3D8R (10 elements through thickness, 1 mm each, 10 mm total) and 27,401 nodes. IMPORTANT: the part's thickness axis is part Y (0.01 to 0.02 before warping). The instance `Plate-1` is rotated so world thickness is Z (plate top at world z = 0, plate body at z in [-0.01, 0]). Work in PART coordinates (simplest) or apply the instance transform consistently, and say which. Warping was only along part Y by `R - sqrt(R^2 - (x^2+z^2))`, so front and back faces are congruent translates.
- `inbox/T-022/p0_curved.py`: the regular-grid prototype (fixture builder, mid-surface fiber prototype, three checks). Reuse its checks.
- `embmesh/` in the project (read only): `parser.parse_deck`, `geometry.inverse_hex`, `geometry.hex_volume`, `volume.fiber_volume_rows`, `fibers._layer_positions`, `fibers.Fiber`.

## Deliverable (outbox/T-022/)
1. `make_one_element_deck.py`: from `Flatv2_curved.inp`, build a Flatv2-style deck for the Plate with ONE C3D8R through the full thickness (top face quads of the 10-layer mesh joined to the bottom face by a single hex per in-plane cell; drop interior nodes). Verify the stack vector s is constant for all hexes (max deviation reported). Keep the same file structure (Part/Assembly/Instance, Ball unchanged) so the mesher can read it. Output `Flatv2_curved_1el.inp`.
2. `stack_and_fibers.py`: given the one-element deck and `--plies N` (try 3, 6 and 10) and fiber diameter `d`: (a) split into N plies by translating by s/N, duplicating interface nodes, ply elsets PLY_1..PLY_N; (b) per ply, lay the 0 or 90 fibers (alternate, 0 first) at pitch d (gap 0), straight lines in the projection onto the plane perpendicular to the stack axis, with polyline vertices at every crossing of an in-plane element EDGE of the projected mesh, plus the d/2 inset at the plate edge (end of fiber at least d/2 inside the projected outline), z at the ply mid-surface (centered). Fibers must be clipped to the actual (irregular, curved-outline) quarter-disc footprint, so a fiber line can enter and leave the footprint more than once; emit each inside run as its own fiber.
3. `check.py`, reporting for each configuration (use h = |s|/N and d just below h*cos(theta_max), and d just above, as in p0_curved.py):
   - theta_max from node spacing (tan(theta) = dz/ds over in-plane edges, and via gradients of the bilinear face), d_max = h*cos(theta_max), N_max;
   - every fiber vertex and every segment MIDPOINT inside a host hex of its OWN ply (inverse_hex, bbox-pruned and vectorized or spatially indexed; this must not be O(vertices x hexes));
   - the maximum distance a segment point is OUTSIDE its host (chord error), measured by sampling the segment at several points, since quads in projection are not parallelograms here;
   - min normal distance from each fiber centre to the ply bottom and top surfaces versus d/2, and whether it agrees with d <= h*cos(theta);
   - shortest fiber segment (tiny segments near node lines shorten the truss dt). Say how many segments are shorter than 5% of the local element edge, and what snapping to the node line (5% tolerance) does to the inside-host check;
   - fiber volume fraction per host element for one ply using `fiber_volume_rows` (with the 1/N-thickness hosts), min/max/mean, and element Jacobian/skew: min and max of detJ ratio and the 1/cos(theta) skew indicator.
4. Plots/VTK: `fibers_ply1.vtk` and a PNG or two of the fibers over the mesh, top view and a side cut, so I can eyeball it.
5. Optionally, if cheap: write one Abaqus deck for the N=3 case (plies, fibers as T3D2 embedded per ply via `*Embedded Element, host elset=PLY_k`, ball and BCs copied from Flatv2) as `curved_3ply_fibers.inp` for a later ROAR smoke run. Only if the checks pass; do not spend long on it. No cohesive interaction yet.
