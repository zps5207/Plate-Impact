# T-058
role: refiner
round: 1
goal: Render the project's 6 standard MP4 views for every run since bt3, locally from the pulled viewer data (no ROAR, no Abaqus), so the T-059 reports can embed them.

## Background
- Older reports embed 6 standard videos per run: passes `status` and `wire` x views `iso`, `side`, `sidev`. Examples: `reports/nc_series_video/v500_*.mp4`, `reports/pw_video/pw_flat500_v3_*.mp4`; captions/meaning in `verification/roar/build_nc_report.py` (~line 110-125), e.g. `wire/sidev` = "Wireframe, fibers blue, symmetry plane (plate vertical, ball travels left to right)". Those were rendered in Abaqus/CAE on ROAR by `verification/roar/render_ghost_failure.py` (read it for colours, what is hidden, camera, fps). Extract a few frames from the example MP4s (imageio/ffmpeg) and match their look as closely as is practical.
- Newer runs only exist locally as viewer bundles (`viewer_<run>/manifest.json` + binary `.f32/.u32/.i32/.u8` files, format `plate_impact_viewer_manifest_v1`; reader logic = `agents/drafter/outbox/T-021/viewer.js` and writer `verification/roar/export_odb_viewer.py`), or as `<run>_viewer.npz` (see `verification/roar/render_bt3_video.py`, pyvista off-screen, already works locally).
- Status pass: plate host elements, deleted ones hidden (or STATUS-coloured like the old renders), ball shown. Wire pass: wireframe plate + fibers blue (fiber-pass rule: see `render_ghost_failure.py` docstring of `set_fiber_display`).

## Deliverable (all in agents/refiner/outbox/T-058/)
1. `render_standard_views.py`: CLI `python render_standard_views.py <viewer_dir_or_npz> <out_dir> [--run NAME] [--passes status,wire] [--views iso,side,sidev] [--max-frames N]`. Reads both formats, writes `<run>_<pass>_<view>.mp4` (H.264, yuv420p, browser-playable), plus a `<run>_views.json` with frame times, camera and settings used. Time label (us) burned into each frame.
2. `videos/`: the 6 MP4s for every run above. Target <= 6 MB each (cap frames/resolution as needed; say what you chose).
3. `contact_sheet.png`: one mid-time frame of each view for 2 runs (one ball test, one nv3), so the Hub can check the look quickly.
