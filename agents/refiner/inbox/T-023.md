# T-023
role: refiner
round: 1
goal: Following T-022, produce a curved, 10-ply, per-ply-embedded Abaqus/Explicit deck that matches the v500 m/s test as closely as possible (same fiber diameter, ball, speed, materials, BCs, step, node contact), so it can be run on ROAR and compared directly with the existing v500 baseline. Also fix the two T-022 problems that block it: tiny fiber segments, and the face-congruence tolerance.

## Why
T-022 showed the curved translation-stack concept works geometrically on the real mesh (0 fibers outside their ply). Before cohesive interfaces are added, we want a plain apples-to-apples impact run: curved plate, per-ply fibers, plies bonded by SHARED interface nodes (no cohesive yet). The only deliberate differences from the v500 baseline are (a) the plate is slightly curved (R = 0.25 m sag, 11.47 deg max slope) and (b) fibers are laid per ply (one layer each, centered) instead of by the monolithic layup.

## Baseline to match (read, do not edit): `Flat-nodecontact/v500/output.inp`
- Fiber: T3D2 truss, `*Solid Section, material=Fiber` area 7.85398163397448e-07 m^2, i.e. **d = 1.0 mm**. Elset names `EMBMESH_FIBERS_T0` / `EMBMESH_FIBERS_T90`, embedded in the host (`*Embedded Element, host elset=EMBMESH_HOST`).
- Plate: 10 layers of 1 mm = 10 mm, 24,000 C3D8R, quarter-disc, symmetry BCs (`X`, `Y` sets XSYMM/YSYMM), `Outside` ENCASTRE.
- Ball: `Ball-1.Ball`, initial velocity -500 m/s in world Z. Step: `*Dynamic, Explicit`, 7e-05 s, bulk viscosity 0.06, 1.2.
- General contact and node contact exactly as the mesher writes them (`embmesh/contact.py`: `EMBMESH_PLATE_NODES`, `EMBMESH_BALL_SURF`, contact thickness). The user has decided **fiber node contact is the contact method henceforth**: include BOTH plate-node and fiber-node contact (`--plate-node-contact --fiber-node-contact` semantics), contact thickness auto.
- Materials Fiber / Matrix / Mild Steel and all property blocks: copy from the baseline.

## Geometry for this task
- Use `outbox/T-022/Flatv2_curved_1el.inp` (2,400 one-element-thick hexes, stack vector (0,-0.01,0) in part coordinates).
- **N = 10 plies**, so h = 1 mm, 24,000 hosts total (same count as baseline).
- **Fiber diameter d = 0.96 mm** (d must satisfy d <= h*cos(theta_max) = 0.98003 mm on this plate; 1.0 mm would not fit at the plate edge). Say clearly in the RESULT that the diameter is 0.96, not 1.0, and why. Use the matching section area pi*d^2/4. Gap 0, pitch d. Ply 1 (ball-facing) fibers along 0 (part X), alternating with 90 (part Z), as in T-022.
- Plies are bonded by **shared interface nodes** (a single node set between ply k and k+1, NOT duplicated) for this task, so the plate behaves as one body like the baseline. Provide a flag `--duplicate-interface-nodes` (default off) that gives the duplicated-node layout from T-022 for the later cohesive work; do not run it now.
- Each ply has its own host elset `PLY_k`; each ply's fibers are embedded only in that ply's host elset (`*Embedded Element, host elset=PLY_k`, one block per ply, or per ply+direction). Fiber elsets should still be named so existing downstream scripts can find `EMBMESH_FIBERS_T0/T90` (keep those two names as unions, plus per-ply elsets `FIBERS_PLY_k`).

The warped plate keeps symmetry planes planar because only part Y was changed; re-derive `Outside`/`X`/`Y` node sets for the new one-element deck and the ply nodes, and check they cover the same geometric locations as the baseline (outer rim, x=0 plane, z=0 plane in part coordinates).

## Fixes required first (from T-022)
1. **Short fiber segments.** After the edge-crossing vertices are placed, merge any vertex closer than 5% of the local in-plane element edge to a node-line crossing (merge to the node line, i.e. move the vertex onto the grid line), drop zero-length segments, and re-verify containment. Target: no segment shorter than 5% of its local element edge, or if impossible state the remaining count and the shortest length. A truss segment shorter than ~0.1 mm sets the stable time increment; report `min segment length / c` with c = sqrt(E/rho) from the Fiber material in the baseline, and compare with the baseline's estimated stable time increment (8.4e-4 ... see `report.json` in a sibling dir for how it is estimated; or just report the segment minimum).
2. **Congruence tolerance.** `make_one_element_deck.py` already rebuilds the bottom face from the top face (max 76 um source mismatch). Keep that, but expose the tolerance and a printed summary (max, mean, 95th percentile mismatch, as a fraction of the median in-plane edge).
