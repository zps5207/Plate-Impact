# T-033
role: refiner
round: 1
goal: Add a "Plywise laminate" toggle to the desktop GUI (`embmesh_desktop.py`) that switches the form to plywise inputs and runs the `embmesh plywise` subcommand, plus a `--preview` flag on that subcommand.

## Context
- The plywise pipeline is complete and in the project: `embmesh/plywise.py` (`write_plywise_deck`), `plywise_contact.py`, `plyfibers.py`, `plycohesive.py`, `plywise_preview.py` (new, written by the Hub: `plot_plywise(deck_path, html_path)` renders plies and per-ply fibers, coloured by angle). CLI example that works:
  `python -m embmesh.cli plywise Meshing/plate1hex_curved_ball.inp --instance Plate-1 --plies 4 --output out/output.inp --layup 0,90,45,-45 --fiber-diameter 0.0005 --cohesion --plate-node-contact --fiber-node-contact --ball-instance Ball-1`
  Read `embmesh/cli.py` (the `plywise` parser block and its handler) for the exact flags. Note `--output` for plywise is a deck FILE path, unlike the `mesh` command's output directory; the GUI's existing output field is a directory, so use `<dir>/output.inp` and put `report.json` and `preview.html` next to it.
- Read `embmesh_desktop.py` fully first (Tk, ttk; contact group, preview button, `_instance_names`, how it builds the command and runs it in a worker thread). Match its style.

## What to build (deliver under outbox/T-033/, mirroring the project)
1. `--preview` flag on the `plywise` subcommand in `embmesh/cli.py`: after writing the deck, call `plot_plywise(output, <output dir>/preview.html)`; also write the printed report to `<output dir>/report.json` (same JSON that is printed). Do not edit `plywise_preview.py` except to fix a real bug (report it).
2. GUI toggle "Plywise laminate" (checkbox near the top). When on:
   - Hide or disable the controls that do not apply to plywise: curved-mode selector and its axis/center fields, host mode / VUEL-ghost options, precise volume, element-set selection, symmetry, node/element offsets. State in the RESULT exactly which controls you disabled and why, based on what the plywise CLI accepts.
   - Show: ply count OR ply thickness (radio; mutually exclusive, validate > 0 / integer >= 1); layup angles entry (comma list, validate floats, show the resulting per-ply list for the chosen N using `plyfibers.expand_layup` with "symmetric" and "repeat" controls; flag a length mismatch before running); fiber diameter, gap, type (truss/beam), fiber material name; thickness axis (auto / x / y / z / vector); cohesion checkbox plus an interaction combobox filled from the `*Surface Interaction` names found in the loaded deck (default `Cohesion` if present; when the deck has none, disable the checkbox with a tooltip/label saying why) and a slave lower/upper selector; the existing ball-contact group stays and maps to `--plate-node-contact/--fiber-node-contact/--ball-instance/--contact-thickness`, plus a ball-interaction combobox listing only interactions WITHOUT `*Cohesive Behavior` (default: automatic).
   - Fibers are optional: an empty layup runs plies + cohesion + contact only. A layup without a fiber diameter is a validation error shown before launching.
   - After a successful run enable the existing preview button; it opens `preview.html`. Show the report's `warnings`, `dangling_impact_references` and resulting ply thickness in the GUI log/status.
3. Make command construction a plain function (e.g. `build_plywise_command(values) -> list[str]`) that takes a dict of field values and has no Tk dependency, so tests can cover it without a display. Keep the existing non-plywise command path byte-identical (add a test comparing the argument list for a representative non-ply setup before/after).
4. Interaction-name discovery should be a pure function too (`list_surface_interactions(deck_path) -> list[tuple[name, is_cohesive]]`), parsing the deck text for `*Surface Interaction, name=...` and whether its block contains `*Cohesive Behavior`. Test it on `Meshing/stack.inp` (expect `Cohesion` cohesive, `General` not).
5. Packaging: check `embmesh.spec` / `Embedded Element Mesher.spec` hidden imports and add the new modules (`plywise`, `plywise_contact`, `plyfibers`, `plycohesive`, `plywise_preview`) if the specs list modules explicitly. Do NOT run PyInstaller.
