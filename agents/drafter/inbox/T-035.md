role: drafter
round: 1
goal: Extend the desktop GUI's plywise panel with (1) a cohesive MATERIAL dropdown (Dyneema HB26 only for now) that computes the cohesive interface from the actual ply thickness, (2) a "collapse layers to one hex" checkbox, and (3) a host-mode selector (native / VUEL+ghost).

## What to build (deliver under outbox/T-035/, mirroring the project)
1. Cohesive material dropdown in the plywise panel: entries "Existing deck interaction" (today's behavior with the `--cohesion` interaction combobox) and the preset labels from `MATERIAL_LABELS` (Dyneema HB26 (Hazzard et al. 2018)). When a preset is chosen: show a rate dropdown (quasi-static / ballistic), a length-units dropdown (m / mm, default m), an interaction-name entry (default from the preset), and a read-only live readout of the computed K_I/K_II (pairs of N/mm^3 and the deck-unit value), strengths and fracture energies for the CURRENT ply thickness. The ply thickness for the readout is whichever is known: the entered ply thickness (ply-thickness mode); or plate thickness / ply count when a deck is loaded and the count is entered (compute plate thickness from the deck bounding box along the chosen axis or reuse an existing helper; if it cannot be known yet, show "enter a ply thickness or load a deck"). Show the preset's warnings (thin ply, units look wrong) in the panel. A preset always overwrites an existing interaction of the same name, so emit `--cohesive-overwrite`; mention that in a one-line label.
2. "Collapse layers to one hex" checkbox -> `--collapse-layers`. Tooltip/label: use when the loaded deck has several hex layers through the thickness (virgin solid decks).
3. Host-mode selector (native / VUEL + ghost) with a ghost-scale entry (default 1e-4, validated 0<x<1) shown only for VUEL + ghost; emits `--host-mode`, `--ghost-scale`.
4. Pure-function command building and validation as in T-033: extend `build_plywise_command`; errors for: preset chosen with no ply count/thickness known and `--length-units` impossible to evaluate, ghost scale out of range, etc.
5. Tests added to `tests/test_gui_plywise.py` (or a new file): command lines for preset + ballistic + mm units; existing-interaction mode unchanged; collapse flag; host-mode flags; the live readout values for a 1 mm ply in mm units equal Table 5 (K_I 60, K_II 36 N/mm^3) and for a 0.1375 mm ply in m units give 4.36e11 / 2.62e11; the Tk smoke test toggles the new controls if a display exists (skip otherwise). Full suite must pass (state count; baseline 120).
6. If `embmesh.spec` lists modules explicitly, make sure `cohesive_materials`, `collapse` are included (T-033 handled the earlier plywise modules).
