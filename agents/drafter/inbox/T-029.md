## Design decisions (the user's, do not re-litigate)
- The plate comes in with ONE hex through the thickness; the mesher splits it into N plies. One ply Part is duplicated as `Ply-1..Ply-N`, pure translations by `step = (top-bottom)/N` (top face is a translation of the bottom face). So a ply is a single hex layer (assume the same oriented, pairing-fixed hexes T-027 produces; local thickness axis may be xi/eta/zeta per hex).
- Each ply holds ONE unidirectional fiber layer on its mid-surface (stack coordinate = ply center). Fiber diameter must be <= ply thickness (error with a clear message otherwise; warn if > 0.8x). Direction = the user's 0-degree reference vector projected into the local surface tangent plane, rotated by the ply angle about the local normal; on curved plates fibers follow the surface (reuse the reference-surface / even-arclength-node approach of `stacked_surface_fibers`, with the same even node spacing and target segment length behavior).
- Fiber Parts: one `Fibers-<angle>` Part per DISTINCT angle, geometry in ply-local coordinates (same frame as the ply Part), instanced once per ply with the same translation as that ply's host instance. Embedding is one `*Embedded Element, host elset=Ply-k.PLY` block per ply instance pairing (check `embmesh/writers.py::append_fibers_to_deck` for the existing syntax and fiber node/element label offsets; labels must be unique per Part, offsets per angle).
- Layup input: a list of angles, one per ply, e.g. `[0, 90, 45, -45]`, plus `symmetric` and `repeat` modifiers; return per-ply angle list of length N (error if it does not fit N).
