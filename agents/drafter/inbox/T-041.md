# T-041
role: drafter
round: 1
goal: Write the fiber material VUMAT (uniaxial, tension-only, rate-dependent yield and damage onset, energy-based softening) with a Python reference, props/svars doc, and single-element test decks plus native-Abaqus twin decks.

## Inputs
- `docs/RATE_DAMAGE_MATERIAL_SPEC.md` (read first, all decisions are fixed there).
- `vumat/VUMAT_tension_only.for`, `vumat/VUMAT_truss.for`, `vumat/VUMAT_fibers_combined.for`, `vumat/reference.py` (style, how truss fibers are fed, material naming by `cmname`).
- `verification/deckgen.py`, `verification/vlib.py`, `verification/make_t7_plasticity.py` (deck-generator style).
- Valerie's FLagSHyP code is read-only and only for reading.

## Deliverable (outbox/T-041/)
1. `vumat/VUMAT_fiber_rd.for`: standalone VUMAT, material name `FIBERRD`, for truss (T3D2) fibers; also say whether the beam (B31) case needs a different branch and handle it if the stress is still uniaxial in component 1. Rules exactly as in the spec: elastic uniaxial, tension-only, J2/uniaxial yield from the log10-interpolated rate table, no hardening, damage onset on equivalent plastic strain vs log10-interpolated fracture strain, energy-based linear softening with ubar_f = 2 Gf / sigma_y0 and L = charLength, D monotonic, stress scaled by (1-D), D=1 gives zero stress and a state flag the deck can use with `*Section Controls`/`*Output` element deletion (set the Abaqus delete state variable in the standard way, `*Depvar, delete=<n>`).
   Props layout: E, Gf, RESSTIFF, RATE_MODE, NYTAB, NETAB then the two tables (rate, value pairs) with a fixed maximum size. Document svars: Epeq, Epeq at onset, sigma_y0, D, status flag, rate, undamaged stress, deletion flag.
2. `docs/FIBER_RD_PROPS_SVARS.md`: props and svars layout tables plus the equations.
3. `verification/fiber_rd_reference.py`: plain-Python implementation of the identical update, plus a driver that prints stress vs strain, Epeq, D and dissipated energy at 0.01, 1, 1000 /s strain-rate-controlled tension, and a compression case (must give ~0).
4. `verification/make_fiber_rd_cases.py`: generates single-truss-element SI decks (Explicit, one T3D2, prescribed velocity giving constant strain rate, smooth amplitude ramp) for rates 0.01 / 1 / 1000 /s, tension and compression, user material `FIBERRD`; and the native twin decks (same geometry, `*Plastic, rate=` hardening table with the rate-dependent yield, `*Damage Initiation, criterion=DUCTILE` with `*Ductile` table of fracture strain vs triaxiality 1/3 vs strain rate, `*Damage Evolution, type=ENERGY` with the matching displacement/energy, density 981, E 135e9, nu 0.45). Output requests: ALLIE, ALLPD, ALLKE, ALLDMD, ALLWK, and S11/PEEQ/SDEG or SDV histories. Write the SLURM script `verification/roar/fiber_rd.sbatch` (all in scratch, Abaqus 2024, `user=` the new file) following existing sbatch conventions in `verification/roar/`; the Hub submits it.
5. `verification/check_fiber_rd.py`: reads the extracted histories (CSV the same way the existing check scripts do) and compares user vs native: peak stress, strain at onset, strain at D=1, total dissipated energy, with tolerances and a PASS/FAIL table.
