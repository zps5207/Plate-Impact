## Reference (read this first): `Meshing/stack.inp`
- Properties: `*Surface Interaction, name=Cohesion` (line ~59672) with `*Cohesive Behavior` (Knn, Kss, Ktt), `*Damage Initiation, criterion=MAXS`, `*Damage Evolution, type=ENERGY, mixed mode behavior=POWER LAW, power=1.`. The mesher must NOT invent these; it references the interaction by name given by the user (`--cohesion-interaction Cohesion`, default `Cohesion`) and errors clearly if the input deck has no `*Surface Interaction` of that name.
- Placement: inside the step, under the `** INTERACTIONS` comment: `*Contact Pair, interaction=Cohesion, mechanical constraint=KINEMATIC, cpset=cohesion` followed by the data line `back, front2` (first surface = slave, second = master as Abaqus defines for contact pair; keep a flag `--cohesion-slave {lower,upper}` and default to what the reference deck implies, state what you inferred). Assembly surfaces are defined just before `*End Assembly`.
- The same deck also has a general-contact block (`*Contact, op=NEW` / `*Contact Inclusions` / `*Contact Property Assignment`) for ball-plate friction. In the plywise deck the ply-to-ply surfaces must not also be picked up by general contact: report how the existing inclusions (`Surf-1`, `Surf-2`, self-contact lines) behave once the plate becomes N plies (does an all-exterior or surface-based inclusion capture interface faces?). Do not change the general-contact block; list findings and a recommendation in the RESULT. That wiring is T-031.
