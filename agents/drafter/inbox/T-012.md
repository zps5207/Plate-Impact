# T-012
role: drafter
round: 1
goal: Build a local PyVista viewer that plays an exported ODB (.npz) as an animation you can rotate, pan and zoom while it plays. Replaces the earlier HTML-viewer plan (docs/INTERACTIVE_VIEWER_PLAN.md) for now.

## Inputs
- `verification/roar/export_odb_viewer.py`: the exporter. Its docstring and code define the .npz format. Read it fully.
- `docs/INTERACTIVE_VIEWER_PLAN.md`: feature list (section "Viewer features") and the rendering rules. Ignore the HTML-specific parts (quantization, three.js, packager).
- `verification/roar/render_ghost_failure.py`: the Abaqus render script. Match its default look (grey host, blue fibers, dark ball, white background) and its rule for what the host wireframe shows.
- No real .npz is on this PC yet. The Hub will place `agents/drafter/inbox/T-012/v500_viewer.npz` when the ROAR export is done. Until then build against a small synthetic .npz you generate with the same keys and dtypes (a few hundred hex elements as a plate, a ball moving through it, a line of fibers, some host elements going STATUS 1 -> 0 over time).

## Format summary (verify against the exporter)
Roles host, ball, fiber. Keys: `times` (frames,), `meta` (JSON string), `<role>_coords0` (n,3), `<role>_pos` (frames,n,3) float32 deformed positions, `<role>_conn_<TYPE>` (elements,k) indices into that role's node list (types C3D8R, C3D6R, T3D2). `host_status` (frames, host elements) uint8, 1 = alive. Host element order = types sorted by name, elements in the order of each `host_conn_<TYPE>` array concatenated in sorted-type order.

## Deliverable
`outbox/T-012/odb_viewer.py`, a single script, plus `outbox/T-012/make_synthetic_npz.py` and the synthetic file. Run as `python odb_viewer.py file.npz`. Uses pyvista (0.49.1 is installed, check pyvistaqt is NOT required; use plain pyvista Plotter with its own widgets/key events/timer so there is no new dependency).

Features:
1. Play, pause, scrub slider, single-frame step (keys), playback speed, loop. Time label in microseconds.
2. Free mouse orbit, pan, zoom at all times, including during playback (playback must not reset the camera). Camera presets by key: isometric, symmetry plane (plate vertical, ball left to right), reset.
3. Host render mode: wireframe, solid, hidden. Wireframe/solid draw exterior faces only: a face is drawn when its owner element is alive and the neighbour across the face is missing or dead (recomputed each frame as STATUS changes; precompute face tables once, per-frame work should be array masking only).
4. Fibers only mode: host hidden, fibers (and optionally ball) shown.
5. Independent colors for host, fiber, ball, background; independent line widths for host, fiber, ball. Provide them as command-line options and as keyboard or widget controls (a simple on-screen menu or key cycling is fine; say which keys in `--help` and on screen).
6. Defaults: grey host #8C8C8C, blue fibers #0033CC, dark ball #606060, white background.
7. Nice to have: host opacity in solid mode, edges overlay on solid.
8. `--save-mp4 out.mp4` option to render the same animation offscreen to a video (fixed camera = current camera preset), and `--screenshot frame_index out.png`.

## Constraints
