## Deliverable (under outbox/T-036/, mirroring the project)
1. `embmesh/collapse.py`: `collapse_layers(deck, instance, thickness_axis=None) -> (new Part, report)` and a text-level writer that replaces the plate Part's nodes/elements and rewrites everything that referenced removed nodes/elements: part-level and assembly-level `*Nset`/`*Elset` (drop removed members; keep sets non-empty or report), element-based `*Surface` elsets on the plate instance (those on the impact face etc.: map each surviving face to the collapsed element if the face lies on the collapsed bottom/top, drop side-face entries that no longer exist and report counts), `*Solid Section` elsets, and keep `Ball` parts/instances untouched. Preserve node and element labels of the surviving first-hex/column where possible. Stack direction: `--thickness-axis` or the shortest bbox extent (use `embmesh.fibers.pick_thickness_axis`).
2. Wire it as an option of the plywise path: `--collapse-layers` (a thin hook that runs the collapse in memory before `build_ply_part`). The result must be exactly what `plywise` gets today from a hand-collapsed deck. Report: layer count per column (min/max, error if columns differ and say which), volume before/after (the single trilinear hex differs from the layer sum on curved plates; report the ratio, expect ~1-2%), top-minus-bottom translation residual max/mean/p95.

Tests in `tests/test_collapse.py`: a synthetic 5-layer flat plate and a synthetic curved translation stack collapse to 1 layer with matching top/bottom nodes; scrambled hex node ordering gives the same result; non-uniform layer counts raise; sets/surfaces are rewritten without dangling labels; round trip through `embmesh.parser`; baseline suite still passes (state count; baseline 93 + T-034).

Real runs, sequential (ask before heavy ones): collapse + `plywise --plies 8` on `Meshing/Flatv2.inp` and on `Meshing/Flat-concave-roar/concave_hostonly.inp` writing into `outbox/T-036/`; re-parse the written decks and report volume ratio, residual, interface coincidence (<1e-9 m), set/surface rewrite counts, and fiber-free ply count (fibers are not part of this task).
