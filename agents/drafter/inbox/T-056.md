# T-056
role: drafter
round: 1
goal: Give freed fibers contact with the host (matrix) elements without non-physical release of initial-overclosure energy. Fibers of ply k contact the hosts of every other ply with ordinary penalty contact, and contact their OWN ply's hosts through a user contact subroutine (VUINTERACTION) that measures penetration from the overlap that existed when the pair was first seen (a "baseline").

## Background (measured by the Hub on Meshing/newvals-elemcontact-tt3/vuel/nv_vuel_elem.inp, the nv3_elem deck)
- 20 plies, each its own instance `Ply-k` of part `Plate`, offset 1.27 mm in z. Ply thickness 1.27 mm, **3 ghost-hex layers per ply** (0.4233 mm each), 3,625 hexes per layer. In-plane hex size median 0.71 mm (graded 0.25..4.5 mm).
- Fibers: `Fibers-Ply-k` (T3D2, section area 3.1371e-7 m^2, so equivalent truss diameter 0.632 mm). **All fiber nodes sit at mid-ply** (ply bottom + 0.635 mm = mid-height of the middle hex layer). In-plane fiber row spacing 0.632 mm, fiber element length about 0.49 mm.
- Fibers are tied to hosts by `*Embedded Element, host elset=Ply-k.EMBMESH_GHOST_HOST` (per ply). Matrix is a VUEL (`VU1`) carried by C3D8R ghost hosts; contact surfaces must live on the ghosts (a VUEL cannot carry a contact surface).
- Current contact in nv3_elem: ghost free faces vs ball, fiber nodes vs ball, and ply k top/ply k+1 bottom cohesive pairs. There is NO fiber-host contact today.
- Clearances with the 0.632 mm equivalent diameter:
  - Fiber node to the nearest face of an ADJACENT ply = 0.635 mm. That is clear if the node-surface offset is half the thickness (0.316 mm), but only by 3 um if Abaqus uses the full thickness. **Verify which convention Abaqus uses for node-based surfaces in general contact** (see Deliverable 1).
  - Fiber node to its own ply's middle-layer top/bottom faces = 0.212 mm, so it is overclosed by about 0.10 mm. Lateral faces of the own-ply hexes range from 0 to about 0.35 mm, so many are overclosed. That is why own-ply contact needs the baseline treatment.
- Background on the energy problem: in earlier coupon tests, penalty contact on embedded nodes with initial overlap made kinetic energy rise from 61 to 89 J and spuriously deleted 709 of 1536 hosts. Abaqus cannot strain-free-adjust an embedded node, so the overlap stays in the penalty spring until the host deletes, and then it is released.
- The interior-face contact pattern already passed a datacheck on real Abaqus: `Meshing/newvals-interior-tt3/nv3_int.inp`, built by `verification/roar/build_newvals_interior_tt3.py` (eroding element surface with EXTERIOR + INTERIOR faces of the ghost hosts, `*Contact Controls Assignment, nodal erosion=YES`, which takes NO data lines).

2. **vuinteraction_baseline.for**: VUINTERACTION with this logic for each contact point:
   - d = current penetration (overclosure beyond the surface offsets).
   - First time the point is seen: store d0 = max(d, 0) and set a seen-flag.
   - Each increment: d0 = min(d0, max(d, 0)). The baseline only ratchets DOWN, so a freed fiber that moves out of the overlap then gets full contact back.
   - Normal pressure = k * max(0, d - d0). Optional Coulomb friction 0.01 to match `General`. Return the stiffness Abaqus needs for the stable increment.
   - Put the penalty stiffness and the friction coefficient in the interaction properties, not hard-coded.
   Also deliver **VUEL_material_plus_vuinteraction.for**: the T-042 VUEL_material.for with the routine appended, unchanged otherwise.
